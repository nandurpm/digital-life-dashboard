# Scripts

## Purpose

Contains maintained helper entry points used to start or prepare Digital Life Dashboard consistently across local environments.

## Contents

- `run-local.mjs` — Validates local run modes and ports, then launches the Vite development server, preview server, or production Node server.

## Responsibilities

Keep scripts deterministic and thin; business rules should remain in the production modules they invoke.
